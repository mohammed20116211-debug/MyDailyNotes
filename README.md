# My Daily Notes
1. افتح المجلد في Android Studio (Koala أو أحدث، JDK 17) وانتظر مزامنة Gradle.
2. شغّل على جهاز أو محاكي (API 26+). للـ APK: Build > Build APK(s).
3. اسمح بإذن الإشعارات (Android 13+). لإشعار ملء الشاشة على Android 14+ فعّل «الإشعارات بملء الشاشة» من إعدادات التطبيق.
## ملاحظات
- التنبيهات تُجدول بـ AlarmManager.setAlarmClock (دقيقة، ولا تحتاج SCHEDULE_EXACT_ALARM) وتُعاد جدولتها من Room بعد الإقلاع/التحديث/تغيير الوقت.
- لم يُبنَ المشروع ولم يُختبر داخل بيئة التنفيذ (لا شبكة لتحميل Gradle).
- غير منفّذ بعد: المهام المتكررة، الإحصائيات، شاشة إعدادات التنبيه (DataStore)، النسخ الاحتياطي، الإنجليزية، اختيار النغمات (حالياً: نغمة الرنين النظامية للبداية ونغمة الإشعار للنهاية).
## بناء APK بدون Android Studio
ارفع المجلد إلى مستودع GitHub جديد، ثم افتح تبويب Actions > Build APK وانتظر اكتمال البناء، ونزّل ملف المخرجات MyDailyNotes-debug-apk وفيه app-debug.apk.
